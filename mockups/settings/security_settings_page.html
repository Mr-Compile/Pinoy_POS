Inactivity Timeout

How long the app waits for input before locking. Unlimited never locks on idle — the 8-hour maximum session length still applies. This is the store default; a per-user override can be set in User Management.

Dropdown replaces the old free-text minutes field. Choices: 3 minutes, 15 minutes, 30 minutes, 1 hour, Unlimited (stored as 0). A previously saved custom value is appended as an extra option.

Session Warning

How long before automatic logout the "Session Expiring" warning appears. It always stays shorter than the inactivity timeout.
